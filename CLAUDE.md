# Gestalt.az — Project Context for Claude

## О проекте
Профессиональная платформа о гештальт-терапии в Азербайджане.
Автор и владелец: Любовь Литовченко (@LyubaLit)
Домен: gestalt.az (также geshtalt.az и gestalt-therapy.az → редиректы на gestalt.az)

---

## Технический стек
- **Frontend:** Next.js (App Router) + Tailwind CSS + shadcn/ui
- **Backend:** Next.js API Routes (Node.js)
- **Auth:** NextAuth.js
- **БД:** PostgreSQL + Prisma ORM
- **CMS:** Payload CMS (планируется)
- **Деплой:** Digital Ocean App Platform ($5/мес)
- **Репозиторий:** https://github.com/lubalit/gestaltAz
- **Языки:** RU, AZ, EN, ES (i18n routing: gestalt.az/ru, /az, /en, /es)
- **Шрифт:** Nunito (Google Fonts, поддерживает кириллицу + латиницу)
- **Аналитика:** Google Analytics G-2X3X4QHW2G, Яндекс Метрика 109372694

### Верхнее меню
- Институты / Организации
- Терапевты
- Эмоции
- Направления
- Документы

### Страницы

#### Главная
- Хедер

- Статьи от новых к старым

## Организации

### Модель данных
- Организация привязана к пользователю, не является отдельным аккаунтом
- Создать организацию может только администратор (Любовь) — пользователи не могут создавать сами
- Привязка: администратор создаёт организацию и связывает с нужным пользователем по email

### Личный кабинет
- Вкладка "Мои организации"
- Если одна организация — открывается сразу
- Если несколько — показывается список

### Управление организацией (стадия 1)
- Лого
- Название
- Аннотация
- Полный текст
- Статьи организации

### Связи (стадия 2)
- Блок "В этой организации состоят" — перечень терапевтов и супервизоров

### Передача управления (стадия 3)
- Администратор может передать управление организацией другому пользователю

## Система верификации терапевтов (4 стадии)

### Стадия 1 — Без модерации
Терапевт заполняет данные, они публикуются сразу без проверки.

### Стадия 2 — Премодерация
Данные проверяются администратором перед публикацией.

### Стадия 3 — Верификация образования
Организации получают запрос на подтверждение диплома.
Статусы: ✅ Подтверждено / 🔄 На проверке / ❌ Не подтвердилась информация
Важно: терапевт НЕ может удалить неподтверждённое обучение — только оспорить через организацию. Это исключает жульничество.

### Стадия 4 — Верификация терапии и супервизии
Терапевт указывает своего терапевта и супервизора (контакты не публикуются).
Им приходит сообщение: "Подтвердите, что за последние 2 месяца у вас был клиент [имя]."

## Принятые решения
- Деплой: Digital Ocean App Platform (не Vercel, не Droplet)
- CMS: Payload CMS (не Sanity, не Strapi) — нативный для Next.js
- Шрифт: Nunito (не Momo Trust Sans — нет кириллицы)
- i18n: через папки /ru /az /en /es в App Router
- Верификация: 4 стадии, терапевт не может удалять неподтверждённое
- Фон: Canvas API с requestAnimationFrame, 18 пузырей
